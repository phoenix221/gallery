Инструкция:<br>
1 - скопируйте файлы проекта в папку веб сервера <br>
2 - в файле config.php укажите настройки подключения к базе данных  (название таблицы, пользователь, пароль, адрес)<br>
3 - укажите настройки подключения к сервису S3<br>
4 - установите зависимости composer.json<br>
5 - откройте проект в браузере<br>
